# Zettelkasten (dev/deep)

This note sits two folders down. A bare [[Zettelkasten]] written here resolves to
*this* note, because it's the nearest one — the same link text on
[[Wikilinks|the Wikilinks page]] resolves to the root note instead.

That behaviour is the single most common thing publishing tools get wrong.
