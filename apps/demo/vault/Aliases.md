# Aliases

This note answers to three names: its filename, `Other Names`, and `AKA`. A link
written as [[AKA]] lands here, and the link is marked as an alias hit so the
theme can style it with a dashed underline.

Real filenames always win over aliases. If someone later creates a note actually
called `AKA.md`, links to it resolve to the file, not to this note.
