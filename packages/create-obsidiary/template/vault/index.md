# My notes

This folder is an ordinary Obsidian vault. Open it in Obsidian, write markdown,
and everything here becomes a website.

Delete this file and write your own.

## What works

- `[[Wikilinks]]`, `[[Wikilinks|with an alias]]`, `[[Wikilinks#Headings]]`
- `![[Embeds]]` that inline the real content of another note
- Callouts, tags, footnotes, tables, task lists, LaTeX, Mermaid
- `.canvas` files, rendered as pages
- Backlinks, a graph, and search — all built for you

## Keeping notes private

If this repository is public, **everything in it is public**. To publish only
some notes, set `explicitPublish: true` in `astro.config.mjs` and add
`publish: true` to the frontmatter of the notes you want online.

Anything not published is never written to the built site.
